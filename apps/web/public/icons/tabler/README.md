# Next-step card icons

Clock, arrow-right and minus (outline), and player-play (filled) are from
[Tabler Icons v3.35.0](https://github.com/tabler/tabler-icons/tree/v3.35.0),
distributed under the MIT license in [LICENSE.txt](LICENSE.txt).

Upstream path geometry is unchanged. `currentColor` is replaced by the card's
pine or sage color so each SVG can be used as a decorative, external image.
