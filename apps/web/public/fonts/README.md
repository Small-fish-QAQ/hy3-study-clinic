# Noto Sans SC

Noto Sans SC by the Noto Project, distributed under the SIL Open Font License 1.1
in [OFL.txt](OFL.txt). Source: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc).

The bundled WOFF2 retains variable weight support and Latin, Greek, punctuation,
mathematical symbols, CJK punctuation, GB2312 Chinese characters, additional
interface characters and fullwidth forms. Other characters use the system fallback. It is served
locally; reading does not depend on a third-party font service.
