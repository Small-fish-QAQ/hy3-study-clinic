# Study Clinic

面向长期、系统性学习的 AI 课程学习系统：把学习材料组织成可持续推进的课程，在讲解、答疑、变式练习与补救中检验理解，并保存学习状态和正式证据。

## 为什么做这个产品

开发者长期使用 AI 自学高等数学、概率论等课程时，遇到了三个相互关联的问题：上下文增长与跨窗口交接让课程安排和学习状态难以连续；基础但重要的知识可能被省略，学习者又难以自行察觉；练习过于接近刚讲过的例题，换一个条件或综合多个知识后才发现理解不完整。

即时答疑能够解决局部问题。长期课程还需要明确的知识范围、可回看的路线、持续保存的学习状态，以及对理解的反复检验。Study Clinic 将这些责任落实在产品流程和持久化数据中，目标是降低遗漏、路线漂移和虚假掌握感的风险。它不保证教材语义绝对无遗漏，也不以一次测试保证真正掌握。

## 学习怎样持续发生

| 学习阶段                   | 系统保留什么、帮助判断什么                                                               |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| 导入材料 → 知识清单        | 保留材料修订、内容指纹、来源片段和不确定项；提取定义、条件、例外、关系与步骤             |
| Course Map → 确认课程      | 将必学知识分配到模块、Lesson和目标；可检查先修、四档深度与考核设计                       |
| 按需 Lesson ↔ Tutor        | 从确认规划生成当前课文；来源可展开，选中片段可追问；历史课堂保留，新问题进入独立回看对话 |
| Practice → Repair / Retest | 用新情境、条件变化、错误诊断及适当综合应用检查理解；针对本次错误补救，再用新题复测       |
| 自愿 Formal → Evidence     | 按冻结能力与代表性要求组卷；只有可信评分流程签发成绩，正式证据只覆盖实际被测知识         |
| 保存、暂停与继续           | 课程、课文、对话、答案草稿、成绩和失败操作持久保存；重启后读回，恢复只处理未完成范围     |

学习者可以选择下一课、暂缓练习或不参加Formal。完成学习路线、日常练习表现和正式测评证据分别记录；未实测知识保持“未实测”。

## 技术上怎样约束生成

- **模型生成语义，服务端管理事实与权限。** React / TypeScript界面、Fastify服务和SQLite保存来源、版本、命令、操作及证据；客户端不能直接写入成绩或Evidence。
- **必要检查与有界局部恢复。** 身份、来源引文、知识归属、正文定位、公开题面和可信答案各有对应检查。完整失败候选保留；修订定位到知识、目标、题目或段落，保护健康成果。
- **题目发布前独立解题。** 独立解题输入不含作者答案；主观题进一步检查参考答案、rubric与公开题面，客观评分由服务端确定执行。
- **同一模型的任务级 auto。** 已实测的MoMA glm-5.3将提取、规划、题目作者、Tutor配为low；Lesson、独立解题、评分和必要核查保守使用high。显式设置优先，其他模型的auto使用平台默认。

具体职责、Prompt与局部恢复边界见[架构](docs/ARCHITECTURE.md)；对照实验依据及失败记录见[研究摘要](docs/REPORT.md#推理强度实验与-auto)。

## 快速运行

推荐 **Node.js 24 LTS + npm**。使用新目录检出：

```bash
git clone https://github.com/Small-fish-QAQ/hy3-study-clinic.git
cd hy3-study-clinic
npm ci
npm run build
npm run dev
```

打开终端显示的前端地址（通常为 http://localhost:5173）。首次运行自动创建独立V2数据库；默认MoMA尚未配置。在“设置 → 模型服务”保存自己的API Base URL、API Key、Model ID，再开始生成课程。实测Model ID为glm-5.3；端点以自己的MoMA模型与套餐为准。

保存的UI配置优先于环境变量。未配置真实模型时明确停止生成；离线体验需显式选择Fake。运行、固定数据路径、自动推理策略、备份和恢复步骤见[SETUP](docs/SETUP.md)。

支持带文本层的PDF、DOCX、PPTX、Markdown、HTML、网页快照与源码文本。扫描PDF暂无OCR，复杂图表和公式提取有限。当前教学与界面以简体中文为主，应用按本地单用户运行设计。

自由Tutor仍可能有事实或措辞错误；高推理强度也可能生成错误。必要检查只能降低风险，不能提供绝对正确保证。长请求可能出现上游结果未知，服务端保留记录而不盲目重发；货币账单未知时不写零费用。公开部署、账号和多用户隔离属于后续工作。

项目继续沿同一仓库main演进，以正式Tag / Release保存阶段成果。[CHANGELOG](CHANGELOG.md)记录V2改变，[历史索引](docs/HISTORY.md)保留两次犀牛鸟发布与旧Hy3 / StudyEval证据。StudyEval v2.0是历史评估器版本，与Study Clinic当前V2产品版本分开说明。
