六份真实返回答卷已冻结：三位标注者 A/B/C，共 68 条评分；27 个题目的 34 个请求维度各有两人填写。**人类之间 24/34 完全一致、9/34 相邻差异、1/34 严重 0↔2 分歧。** 二人相同判断的 24 个维度上，StudyEval 为 20 个一致、2 个相邻差异、2 个 U，没有严重反转。这个共识子集不代表全部 34 个维度，完整评分的比较同时公开。

## 原件、解析与缺失元数据

接收后先逐字节备份六份 DOCX、计算 SHA-256，并将私有保存副本设为只读；随后才解析。使用 OOXML XML 解析和独立的 python-docx 表格解析逐格交叉核对，评分、理由与题目顺序全部一致。[原件哈希及公开副本记录](../eval/final-evaluation/human/original-hashes.json)绑定了来源。

五份原件的隐藏修订属性含个人邮箱，因此原件集合保持私有。公开的[六份审阅副本](../eval/final-evaluation/human/review-copies/)仅清除文档属性和自定义 XML 元数据；每份 `word/document.xml` 及正文/页脚/样式内容字节均与原件相同。它们是去元数据副本，不被称为原始文件；原件和公开副本分别保留完整文件哈希与正文 XML 哈希。

归一化只去除评分字段首尾空白，例如将带尾随换行的 `2` 读为数值等级 2；原始评分字符串和理由全文仍在[normalized.json](../eval/final-evaluation/human/normalized.json)。没有修改理由、推测分数、补齐时间或用理由覆盖填写的等级。

六份答卷的开始时间、结束时间和流程/外部帮助说明均为空，统一记录为 **not provided（未提供）**。文件修改时间和 Word 创建时间不是标注用时；空白备注也不能证明没有外部帮助或没有接触已经公开的材料。用户确认这些是真实返回答卷；已提供的独立填写要求可以核查，实际执行的盲评条件不能由空白元数据进一步认证。对人类用时、严格独立性或群体代表性不作额外推断。

原始盲评包、预先选定的题目映射和模型输入哈希现在均已公开。A 填包 1+2，B 填包 2+3，C 填包 3+1。标注来自三个人，68 条评分是对相同材料的重复观察，不是 68 个独立样本。

## 模型预先标记的歧义与人类分歧有多少重合

Max/Fable 各标记七个歧义维度，并集九个。在十个人类分歧维度中，**同维度重合三个**：P1-03/Q2、P2-06/Q4、P3-08/Q1，即模型标记的 9 个维度中有 3 个出现人类分歧，未标记的 25 个中有 7 个出现分歧。这不支持“多数人类分歧集中在模型预警维度”的说法。

若只按题目合并，重合是五个题目：上述三个再加 P1-08 和 P3-02。后两者的模型歧义标记与人类分歧发生在不同维度，不能合并成同一语义问题。最明确的重合是 P2-06：两模型均预警，且这里出现了唯一严重人类分歧。

## 四类实验不能合并成一个“准确率”

- **受控配对判别**：40/50 个双方有数值的质量对排序正确；全部预定对为 40/72。参考是构造者预先假设。
- **严格三档排序**：5/24 组满足完整 2>1>0，要求高于单个配对正确；仍须披露。
- **同一输出重复稳定性**：44 个维度组中 29 个三次类别完全相同；有一次 0→2 转变，是 StudyEval 自身的重复实验。
- **首次独立审阅对齐**：人类配对、共识子集、全部人类评分与 34 条首次模型评分各有明确分母。StudyEval/Max/Fable 的 34 条两两比较没有 0↔2；人类之间及全部人类评分对 StudyEval 则各有一项，均是 P2-06。

Max/Fable 仍是独立模型审阅者，不是人类真值。当前人工验证是一组小型、预先选择的受控/自然混合材料，且缺少时间及实际外部帮助记录；它提供具体语义判断对齐证据，不是对所有产品内容、所有人群或学习效果的认证。

## 从答卷重算

在仓库根目录执行（Python 3 标准库，无第三方依赖、网络或模型请求）：

```bash
python eval/final-evaluation/scripts/verify-human.py
```

脚本重新打开六份公开去元数据 DOCX，逐格解析 68 条原评分和理由，验证归一化 JSON/CSV、空白元数据、预定包映射和模型 CSV 来源；核对全部 74 条冻结 StudyEval packet 答案，再用 34 条 PRIMARY 结果重算所有表格、逐题比较及歧义重合。十个未达共识的维度保持未裁决，所有人类及模型原始答案不变。
