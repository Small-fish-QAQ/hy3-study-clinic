# Study Clinic 产品与技术研究报告

适用版本：V2（2.0.0）。

更新：2026-10-15。已验收产品基线9ec6bde693455eac3df00e33984d9e0e0d9d8c93。正文说明当前产品、真实研究和证据边界；[历史索引](HISTORY.md)保留Hy3、StudyEval与两次犀牛鸟发布。

## 产品问题与设计回应

开发者在长期用AI学习高数、概率论等课程时，体验到上下文增长、跨窗口交接、基础知识遗漏及练习贴近原例题的问题。学习者很难仅凭顺畅对话判断课程是否完整、换题后是否仍能运用。

Study Clinic面向愿意导入课程材料、持续自学的学生与开发者。显式知识清单使范围可检查；确认Course Map让路线与目标持久化；按需Lesson与Tutor提供讲解和即时追问；Practice、Repair/Retest用条件变化、新情境与综合应用检查理解；自愿Formal通过独立题目准入、可信评分和Evidence保存被检验的范围。

学习路线、日常诊断与正式证据分别记录。暂停和重启读回原状态，局部失败不抹去健康成果。产品目标是降低风险，并未证明语义绝对无遗漏或真实学生成绩提升。

## 实际MoMA应用与职责

当前实测Provider为MoMA，模型glm-5.3，端点https://zhenze-huhehaote.cmecloud.cn/v1。使用同一模型承担知识提取、完整／局部规划、Lesson、Tutor、题目作者、独立解题、rubric核查、Repair及主观判分。服务端管理来源、身份、范围、版本、权限、客观评分、总分和Evidence。

接入层支持OpenAI兼容端点：API地址、Key和Model ID由用户在设置中配置，并可获取模型列表。其他兼容模型可通过同一接口配置；自动推理策略仅对MoMA / GLM-5.3发送任务级档位，其他模型默认不附加reasoning_effort。对明确不支持该参数的400/422响应，至多一次去掉字段重试。该兼容能力不代表其他模型已完成相同验收，也不构成多模型自动调度。

流式HTTP只接纳完整正文，保留Input/Output、reasoning分项和实际deadline。超时、格式失败、内容拒绝与结果未知分别记录。详见[现行架构](ARCHITECTURE.md)及[集成阶段原始报告](REAL_MOMA_INTEGRATION.md)。

产品可靠性验收检查代表性用户路径、必要正确性、普通冷启动和持久化恢复。最终研究冻结31通过这些门槛，完整教材冷启动实际在冻结24执行；后续改动做定向复验与最终读取／重启核对，没有把冻结31写成重新生成全部课程。

## 推理强度对照与任务分配

推理强度对照实验在产品可靠性验收通过后进行；发现必要核查缺陷时先修复并复验，再建立新冻结版本对照。协议在请求前冻结，原始失败、评价修订、被排除缓存及不同freeze保留。

同组固定模型、完整输入、Prompt/Schema、temperature=0.2、max_tokens=24,000、deadline=240,000ms，只改变reasoning_effort，交叉顺序。实际103次发送中98次为内容对照、5次能力探针；普通任务每档通常2次，复杂证明与部分评分3次。生产默认预算的7次复验另计。

以下数字为选定样本的内容审查通过数和请求耗时中位数，不代表任务总体正确率：

| 样本／冻结版本     | low正确/次数 | high正确/次数 | low／high中位秒 | 决策作用                           |
| ------------------ | -----------: | ------------: | --------------: | ---------------------------------- |
| 普通Tutor／25      |          2/2 |           2/2 |       6.9／15.1 | 低档在此样本更快                   |
| 复杂嵌套CP／25     |          3/3 |           1/3 |      27.6／46.7 | 高档没有普遍质量优势               |
| 独立运动学解题／25 |          0/2 |           2/2 |      11.8／16.4 | 低档混淆带符号位移与路程，保留高档 |
| 修复后局部规划／26 |          2/2 |           2/2 |       9.1／35.0 | 合同修复后两档均通过，低档更快     |
| 隐藏评分要求／26   |          1/2 |           2/2 |       7.2／18.6 | 保留高档判分                       |

四个Tutor输入跨指定受控组每档9次，low9/9、high7/9，仅描述这18个已审查输出。全部首次规划与Lesson作者仍出现过缺陷，high作者没有已证明的总体优势。其他失败、正负核查与补充实验见[完整研究记录](RELIABILITY_AND_REASONING_STUDY.md)和[冻结协议](REASONING_EXPERIMENT_PROTOCOL.md)。

已实施“按任务分配推理强度”策略（设置项“自动 / auto”）：提取、完整／局部规划、题目作者和Tutor使用low；Lesson作者、独立解题、主观判分、必要Lesson/scope/rubric核查及Repair保守使用high。显式偏好优先，仅对实测MoMA glm-5.3应用此策略；其他模型auto采用平台默认。这是同模型任务级档位分配，没有动态复杂度判别Agent或多模型智能路由。

生产预算／期限下7次复验首次技术完成6/7；一个正确拒绝歧义题的完整候选因不适用空cell标注结构失败，归一后17ms、零新请求恢复，最终七项控制结果完成。它不是发布了不可解题。最终UI Tutor所求证明正确，但附带XOR措辞不完整，记录fullResponseCorrectness=false，保留自由答疑风险。

## 研究请求与用量口径

研究账本记录580次真实发送，574次有完整平台Input/Output：2,639,550 Input + 777,748 Output = **3,417,298已报告Tokens**。reasoning分项293,496单列，不重复相加；缺失用量不视为零。

物理状态为521次技术完成、37次内容拒绝、20次已知传输／输出失败、2次上游结果未知。技术完成不等于内容正确。103次受控实验占414,743已报告Tokens；其他请求包括历史续修、产品验收和策略／恢复复验，不混成同基线重复试验。请求耗时中位17.9秒，所有请求计时之和约249.6分钟，含失败与等待，不能视为用户完整学习时间。

上述研究统计不含后续独立最终UI修复阶段的4次发送，也不含B线新增拍摄调用；未经物理请求去重不相加。模型用量按实际返回的输入与输出Token记录，后续学习继续复用已保存内容。

## 2026-10-14最终真人验收

真人实际课程为8模块／17Lesson／35必学知识／39目标，与32K研究冷启动课程是不同实体。用户已完成完整教学闭环体验。最终工程验收从原失败库独立副本出发，冻结104个生产文件，普通页面只点一次恢复：

- 64,633ms完成失败Lesson；局部作者56,626ms、既有必要核查7,863ms。
- 2次MoMA调用，4,215 Input + 2,393 Output = 6,608 Tokens，没有全量重购Lesson。
- 五个健康段落、来源和范围外教学覆盖保留；重启后9张相关表hash一致，读取课文零新增模型请求。
- 原用户库、Provider、Key、.env和此前3,145份受保护成果保持；真实恢复及删除验收均使用隔离副本。

包括探索在内，该阶段共4请求、13,359已报告Tokens。探索中改代码并复用候选的结果仅属调试；冻结后重新开始的验收单独记载。[最终验收全文](FINAL_HUMAN_ACCEPTANCE_20261014.md)。

导航、课程管理、学习中心及390px选课界面通过代表性检查。最终工程363项（shared20/server295/web48）及构建、lint、离线合同、localhost HTTP回归通过。这些数字不等于教学正确率。

B线公开截图记录真实持续学习状态：2/17Lesson完成、所选模块一次100%成绩和4条Evidence；不能解释为整课完成或全部知识掌握。B新答疑／作答演示另附素材来源，新增模拟作答不进入研究学习效果分母。本次素材采集另有20个真实逻辑调用，报告153,783 Input + 40,696 Output = 194,479 Tokens；reasoning 20,689单列。这些调用取得完整响应，三轮新补救仍未完成，内容准入失败与原记录保留，不称为全部候选成功。

## 用户体验与已知限制

开发者定性验收确认课程、课堂、答疑、练习、补救、正式记录和重启继续能够衔接。没有独立学生样本、对照学习实验、用户规模或提分数据。

剩余限制包括：完整正常冷启动样本只有一份；文字提取无法保证扫描原图与复杂公式；同一助手内容评价存在偏差，模拟学习者曾接触候选；自由Tutor可能出现事实或措辞错误；作者首次输出仍有缺陷，高推理也会错误；长请求可能结果未知；reasoning元数据分项偶有不一致；历史LaTeX显示有限。确定性覆盖与来源检查不能穷尽教材语义正确性。

## 应用价值、成本与发展

近期用户是长期自学的大学生、转专业学习者与开发者。现阶段是可运行的本地开源应用，用户自备Key，围绕课程组织、持续状态和可信自测积累使用反馈。

学习成本通过控制模型用量来降低：课程准备样本使用190,518输入与输出Tokens、27请求、约9分22秒，形成32个知识点和17课规划；单次课文局部恢复使用6,608Tokens、2次请求，保留5个健康段落。两者属于不同任务，不作为成对节省比例。已保存内容的读取不产生新增模型请求；新课文、答疑、练习和评分仍按需调用，不能把完整学习过程写成零生成成本。

| 路径 | 服务方式 | 当前状态与下一步 |
| --- | --- | --- |
| L0 本地开源 | 自备Key，导入自有材料 | 已有可运行产品与完整定性验收 |
| L1 个人服务 | 订阅、托管连接、跨设备状态、材料库 | 未来建设，验证付费意愿 |
| L2 机构服务 | 组织部署、账号权限、可审查学习记录 | 未来建设，验证采购与隔离需求 |
| L3 课程服务 | 按课程或人年提供课程支持 | 未来探索，以Token用量核算单位成本 |

医疗住培与继续教育、金融从业培训、政务政策培训和工业安全规程培训具有课程范围与学习记录需求。知识清单、版本绑定、正式支持分级和局部恢复可作为这些方向的技术基础；行业部署还需专业内容审校、权限和组织隔离，当前没有相应客户实绩或合规认证。

工程积累集中在范围治理、证据分级与持久状态：六类持久操作、幂等／租约／fence、schema 7和363项工程验收结果。客户规模、收入、转化率与教学提升均未验证，商业路径属于未来计划。
