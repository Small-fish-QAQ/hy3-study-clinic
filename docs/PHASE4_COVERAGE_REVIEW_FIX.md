# Phase 4 — 覆盖 Review 的容量、超时与恢复

本轮修复 `req-d` 的已确认失败点：Detail 生成前的独立覆盖义务 Review 合并 4 个区域、137 项证据，消息 19,517 字节，在本地 240 秒上限终止。连接探测已成功，不需要为验证此修复反复进行探测。

## 执行与正确性

来源义务先按整个 Course Map 的来源与学习意图独立提取，初次提取不提供任何候选教学目标。Review 依据证据数、实际 UTF-8 请求体和本地输出估计进行稳定连续分批；不使用 Detail 的两批作为 Review 边界。

一个完整区域是最小语义单元。区域内证据、条件、例外和步骤不会为适配容量被抽样或截断。每份结果保留原有 Schema、精确区域顺序、来源引用及短引文校验；合并必须对应完整且唯一的输入区域清单。后续目标映射、覆盖缺口修复、目标权限评估及 Formal 门槛继续执行，缓存或分批本身不能授予通过。

Review 单次规划上限为 64 项证据、12,000 请求字节、6,144 本地正文目标 Token；输出估计含 25% 余量，且不降低 Schema 的能力/引文允许范围。复杂度估计可能不足，模型响应仍须完整通过校验，不能默认通过。

MoMA/GLM-5.3 的模型选择与深度思考保持不变。正文目标随任务规模规划，追加既有固定 12,000 Token 的本地推理余量，并服从模型配置的总输出上限。这是本地总预算规划，不声称上游分别保留推理/正文配额，不发送未经该 endpoint 确认的思考参数。单次请求仍最多 240 秒，不因超时增加 Token 上限；结构修正也使用同一预算，最多一轮。

## 缓存与两个边界

每个有效 Review 批次使用已有生成依赖缓存，身份包含实际 Review 语义输入、来源、学习意图、Provider、Model、endpoint、运行策略与预算。Detail 的 batchKey 或教学目标数量容量变化不会单独撤销相同语义输入的 Review。恢复重新检查精确绑定及当前取消、来源与执行权边界；失败或部分响应不进入成功缓存。

多区域任务发生超时时，可以沿稳定二分树分解为更少的完整区域，直到单区域。一次 N 区域任务最多访问 2N−1 个逻辑任务节点；每个节点内部仍受 Provider 的有限传输与修正次数约束，并逐次执行成本策略、当前操作/课程准备租约和取消检查。失败的父调用保持失败，不把本地聚合伪装成一次成功模型推理。`coverage_review_timeout` 记录经过实际调用账本证明的超时；下一次恢复跳过已失败父任务，直接使用子任务和已完成缓存。

两个边界仍可能阻断完成：

- **单区域超容量：** 在任何额外模型请求之前返回 `curriculum_coverage_capacity_exceeded`，提供不含来源正文的规模元数据。已保存概念、Map、Review 依赖保持可用。现有语义协议无法安全证明区域内任意切片仍保留联合条件，因此本轮不切碎区域、不降低检查；相同输入重试不会产生额外付费请求。
- **单区域仍超时：** 返回 `curriculum_coverage_minimum_timeout`，保留完成进度。相同任务/模型/endpoint/预算/等待配置的普通重试不再发送这一请求。需要后续明确调整有界任务或预算策略后验证；本轮没有增加 UI 强制重复付费入口，也没有静默换模型或关闭思考。

超时恢复记录可以跨原操作重新领取执行权使用，但须匹配原事件与已发送、已失败 `PROVIDER_TIMEOUT` 调用的执行权 token；取消、结果未知和未发送尝试不能被当作已证实的超时。

## 安全诊断与下一次验证

`provider_request_diagnostic` 与实际物理 attempt 对齐，记录请求字节、实际 max_tokens、Review 类别/区域/证据数、等待响应头耗时、读取响应体耗时、是否完整读取、HTTP 状态、总耗时与用量是否已知。只保存闭合标量字段；不记录 API Key、endpoint、提示词、原始响应体或来源正文。缺失 usage 保持未知；没有流式首 Token 观测时不推断上游是否已经生成、排队或消耗 Token。

用户授权真实验证后，重启应用，保留 MoMA/GLM-5.3，在原课程重试即可。概念和 Map 本地复用；此次尚无成功 Review/Detail 可复用，所以预计先购买 7 份来源义务 Review，再购买两份 Detail、按实际义务规模分批的目标映射 Review及目标权限评估。必要的有界内容修正或完整区域超时拆分会增加调用。此后失败再次重试时，只购买未完成且没有最小超时阻断的任务。

真实响应时延、预算充足性及语义教学质量尚未验证。更多小任务会重复固定提示词并增加调用开销；本地中止也不能证明上游停止生成或计费。Phase 4 尚未关闭。
