# Post-Practice recovery

A wrong informal Practice answer opens targeted recovery inside the same Lesson
execution. It does not create a Formal Repair episode, grade, Evidence record,
mastery state, review target, or Curriculum objective.

The accepted Brief supplies the exact objective, tested capability, selected
option feedback, teaching exposure, and source context. The learner may add their
reasoning. Hy3 proposes a diagnosis, causal explanation, worked example, contrast,
and two self-contained retest questions. Local validation checks the structure
and obvious replay. The existing independent teaching reviewer solves the retest
without author keys and checks concrete content defects. Its verdict is a content
gate only; it has no credit authority.

Only reviewed content is persisted in the failed attempt's recovery field within
`lesson_execution_states.practice_interactions`. Existing command identities,
optimistic versions, leases, source/route fences, telemetry, and recoverable
generation stages own preparation and retries. A failed review retains the draft
and findings for an explicit correction. Cancellation during review can reuse the
completed author stage after restart. Migration 48 only extends the Lesson event
constraint, preserving existing rows.

The learner reads Repair before starting Retest. Retest hides teaching, hints,
feedback, and answer keys until commitment. Both new questions must be correct
in one round. A failed retest remains unresolved and uses its actual response in
the next repair. Three unsuccessful rounds call for deeper support and a new
learner explanation before continuing. Only the latest three packets stay in the
active state; older packets are retained in Lesson events and their prompts enter
the bounded novelty context. Tutor receives the failed capability and already
revealed material, never the unseen retest answer.

Passing recovery satisfies only the current informal Practice item. Other items
remain required. Completing Practice invokes the existing teaching-completion
and Agenda continuation service. Any planned Formal checkpoint remains governed
by the existing source admission, grading, credit, mastery, and review policies.
Teaching-only routes continue with their explicit lack of Formal evidence.

Historical completed Lesson executions remain readable. New failures cannot
complete Practice by exhausting retries. Generated correctness and novelty remain
fallible; lexical checks and independent review are bounded safeguards, not proof
of universal teaching quality or measured learning effectiveness.
